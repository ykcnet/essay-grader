# 評語庫五面向與結構依據

> 檢索日期：2026-11-20
> 用途：作為 `junior.draft.json` 與 `senior.json` 總評（category=comment）編寫、校正與覆蓋率檢查的依據。
> 範圍：國中教育會考寫作測驗、高中職學測國語文寫作能力測驗，以及教學現場常見的寫作問題。

## 一、總評以五面向編寫，結構只是其中之一

作文的問題不只出現在段落安排。學生可能切題但語言空泛，可能例子充足但情感沒有展開，也可能書信內容豐富卻格式缺漏。若總評全部從結構出發，老師遇到立意、用詞、情感或格式問題時，就沒有合適的評語可選。因此本庫把總評分成五個面向，結構是其中一個，不是唯一主軸。

| 面向（key） | 定義 | 涵蓋範圍 |
|---|---|---|
| 結構（structure） | 文章如何組織與推進 | 主旨貫穿、段落功能、比例、順序、過渡、主題句、首尾、完整度、重複精簡 |
| 立意取材（content） | 文章說什麼、為什麼這樣說 | 切題、材料選擇、見解深度、觀點、理由、例證、分析、反思、材料統整 |
| 語言表達（language） | 文章怎麼說 | 用詞、句式、語氣、修辭、節奏、精準、具體、流暢、冗贅、標點 |
| 情感體驗（emotion） | 文章讓讀者感受到什麼 | 情感線、真摯、節制、共鳴、內心、場景、轉折、體悟 |
| 格式應用（format） | 文章是否符合體例與溝通目的 | 書信、通知、啟事等格式、稱謂、署名、對象、資訊順序、重點、收束 |

每一條總評至少屬於一個面向，可跨兩個面向；同一條可重複計入多個面向。最低條數以每套 72 條 comment 計：結構 30、立意取材 12、語言表達 10、情感體驗 10、格式應用 8。非結構面向的評語不硬塞結構詞，例如語言面向可以只談用詞與句式，情感面向可以只談情感線與場景，格式面向可以只談格式與資訊順序。

## 二、官方評分規準對結構組織的描述

### 1. 國中教育會考寫作測驗

官方採四向度整體性評分：立意取材、結構組織、遣詞造句、錯別字格式與標點；不另訂固定比重。與結構直接相關的描述如下（摘要）：

| 級分 | 結構組織描述 |
|---|---|
| 六級分 | 結構完整，脈絡分明，內容前後連貫 |
| 五級分 | 結構完整，但偶有轉折不流暢 |
| 四級分 | 結構大致完整，但偶有不連貫、轉折不清 |
| 三級分 | 結構鬆散，或前後不連貫 |
| 二級分 | 結構不完整，或僅有單一段落但可區分出結構 |
| 一級分 | 沒有明顯結構，或僅有單一段落且不能辨認結構 |
| 零級分 | 完全離題、只訂題目、僅抄寫題目或題幹、使用詩歌體、空白卷 |

官方同時強調引導寫作須依題意完成任務；立意取材向度包含統整材料、凸顯主旨，零級分則包含完全離題。也就是說，結構不是只有分段，還包含切題、主旨、材料安排與全文完整度。

### 2. 學測國語文寫作能力測驗

官方分知性統整與情意感受兩大題，採三等六級評分。與結構直接相關的描述如下（摘要）：

| 題型 | 高分結構訊號 | 低分常見結構問題 |
|---|---|---|
| 知性題 | 結構嚴謹、層次井然、條理分明；立場、理由、例證、反駁、結論能依序展開 | 結構鬆散、立論含糊、觀點不清、論述不連貫、只摘要未分析、未回應材料 |
| 情意題 | 結構完整或嚴謹、文辭暢達、情感深刻；能陳述原因、換位思考並傳達回應 | 結構鬆散、內容空洞、情節薄弱、空泛抒情、敘寫雜亂、結尾無法收束 |

### 3. 官方規準的共同訊號

- 結構完整：段落齊備，有開頭、開展與收束，不是只有一段或中途停筆。
- 脈絡分明：段落有先後關係，時間、因果、輕重能說得通。
- 前後連貫：段落之間有過渡，轉折有原因，不突然跳接。
- 層次井然：主張、理由、例證、反駁、結論有推進順序。
- 首尾呼應：結尾回到開頭提出的問題、畫面或主旨，不另開新線。
- 切題與任務回應：材料與段落都為題目服務，沒有離題或只抄題幹。

## 三、五面向分布與最低條數

`comment-coverage.json` 的 `dimensions` 是五面向的唯一來源。同一條 comment 可跨面向，因此「面向歸屬次數」會大於 72。

| 面向 | 最低條數 | junior 條數 | senior 條數 |
|---|---:|---:|---:|
| 結構 | 30 | 33 | 33 |
| 立意取材 | 12 | 21 | 25 |
| 語言表達 | 10 | 12 | 12 |
| 情感體驗 | 10 | 20 | 18 |
| 格式應用 | 8 | 10 | 10 |
| **面向歸屬次數** | | **96** | **98** |

## 四、19 類結構症狀清單（教學歸納）

以下 19 類是教學現場、教學資源與使用者提供評語表的歸納，**不是官方分類**；官方只提供向度與級分描述。前 16 類是通用結構檢查，後 3 類是體裁補充（記敘、抒情、議論）。

`categories` 保留為結構症狀的輔助索引，不再要求每一條 comment 都被結構分類覆蓋。若某條已改以語言、情感或格式為主，就不再硬掛在結構分類；表格中的 ID 只列真正處理該症狀的評語。

| # | 分類（key） | 症狀 | 調整策略 | 依據 | 對應 comment（junior／senior） |
|---:|---|---|---|---|---|
| 1 | 切題與主旨（topic-focus） | 背景或枝節蓋過題意；讀完不知道全文主張；段落各自發展 | 先審題，用一句話定出主旨；刪去無關段落；各段回扣同一主張 | 官方：立意取材、零級分離題／教學歸納 | JC-01、07、36、40、69／C-01、07、36、40、69 |
| 2 | 段落功能與分段（paragraph-function） | 一段同時做太多事；段落界線不清；全文只有一段 | 依功能分段，一段只擔負一個任務；過渡內容併入相鄰段或獨立成短段 | 官方：二級分單一段落／教學歸納 | JC-02、15、27、46、65／C-02、15、27、46、65 |
| 3 | 段落比例與重心（paragraph-proportion） | 頭重腳輕；背景占大半；次要事件搶走篇幅 | 主要事件多寫，背景壓縮；刪去次要事件，讓重心集中 | 官方：布局謀篇、結構完整／教學歸納 | JC-08、13、24、62／C-08、13、24、62 |
| 4 | 順序與脈絡（order-coherence） | 時間或因果跳躍；段落先後任意；事件與反省錯位 | 依時間、因果或輕重重新排列；先發生先寫，反省放在事件之後 | 官方：脈絡分明、前後連貫／教學歸納 | JC-28、38、61、70／C-28、38、61、70 |
| 5 | 過渡與連貫（transition） | 換段突然；轉折沒有原因；場景直接跳接 | 換段前補時間、地點或因果過渡句；轉折前先交代發生什麼事 | 官方：轉折不流暢、前後不連貫／教學歸納 | JC-05、14、22／C-05、14、22 |
| 6 | 主題句與段落重心（topic-sentence） | 段首沒有主題句；段內細節發散；讀到最後才知道重點 | 把該段中心想法移到第一句；段內例子與細節都要支持這個重心 | 官方：條理分明、層次井然／教學歸納 | JC-02、20、43、46／C-02、20、43、46 |
| 7 | 例證與論據（evidence） | 只有主張沒有證據；例子太抽象；數據沒有來源 | 補具體事例、數據或個人經驗；標明時間、場合與來源 | 官方：統整運用材料、舉例恰當／教學歸納 | JC-11、18、25、35、56／C-11、18、25、35、56 |
| 8 | 例證與論點連結（evidence-link） | 例子和主張各說各話；引用後沒有解釋；結論接不上例證 | 例子說完補一句它和論點的關係；結論回到前面的例證再收一次 | 官方：舉例不當、內容不切情理／教學歸納 | JC-06、23、33、71／C-06、23、33、71 |
| 9 | 首尾與呼應（intro-outro） | 開頭和結尾無關；結尾另開新線；開頭的伏筆沒有下文 | 開頭提出問題或畫面；結尾回到同一條線索，形成閉合 | 官方：首尾呼應、結構完整／教學歸納 | JC-04、10、30、49、68／C-04、10、30、49、68 |
| 10 | 結尾收束（ending） | 事情說完就停；只留口號；結論出現太早或太晚 | 補一句意義、改變或具體行動；讓結尾回應主旨，不另開新線 | 官方：結尾無法收束、結構完整／教學歸納 | JC-10、17、32、45、68／C-10、17、32、45、68 |
| 11 | 重複與精簡（repetition-concision） | 同義段落反覆出現；說明過長；篇幅虛胖 | 刪去重複段落與同義說明；把篇幅留給關鍵轉折 | 官方：冗詞贅句、重複敘述／教學歸納 | JC-21、37、67／C-21、37、67 |
| 12 | 知性題論證層次（intellectual-argument） | 立場不明；理由不足；只摘要不分析；缺反駁；結論弱 | 依立場、理由、例證、反駁、結論推進；至少三段，每段一個層次 | 官方：學測知性題結構嚴謹、層次井然／教學歸納 | JC-26、31、34、39、72／C-26、31、34、39、72 |
| 13 | 情意題情感線與場景（emotional-line） | 空泛抒情；情節薄弱；場景堆砌；轉折太快；結尾無收束 | 用場景與動作承載情感；安排轉折與節奏；結尾回到情感線 | 官方：學測情意題結構完整、情感深刻／教學歸納 | JC-24、27、41、42、66／C-24、27、43、44、66 |
| 14 | 應用文格式與資訊順序（applied-format） | 格式缺漏；對象不合；資訊順序亂；重點不明；結尾無收束 | 先確認對象與目的；依格式與輕重安排資訊；補一句收束 | 官方：格式向度、實用文體資訊完整／教學歸納 | JC-51、53、55、57、60／C-51、53、55、57、60 |
| 15 | 完整度（completeness） | 未完成；沒有結尾；一段成文；關鍵場景只交代結果 | 時間不足也要收尾；補足關鍵段落與轉折，讓文章有完整意義 | 官方：結構不完整、僅單一段落／教學歸納 | JC-17、30、48、64、68／C-17、30、48、64、68 |
| 16 | 文體與任務回應（genre-task） | 文體不符；沒有回答題目任務；只抄材料沒有改寫 | 先判斷文體與寫作目的；再決定段落功能、語氣與材料取捨 | 官方：引導寫作、知性與情意任務／教學歸納 | JC-25、55、58、69／C-25、55、58、69 |
| 17 | 記敘結構（narrative-structure） | 時間線跳躍或回溯錯位；詳略平均；只有概述缺場景；事件與體悟斷裂 | 依時間重排並補過渡；關鍵場景寫透；用動作與對話取代概述；補上轉念環節 | 使用者提供評語表＋教學歸納 | JC-61、62、63、64／C-61、62、63、64 |

## 六、維護方式

- `packages/core/src/library/comment-coverage.json` 是五面向與結構分類的唯一來源；本檔兩張 ID 表須與它一致。
- `npm run library:coverage` 會檢查：五面向 minimum 與 ID、每條 comment 至少屬於一個面向、19 類各至少 2 條、兩份 Markdown 同時含五面向分布與結構覆蓋摘要。
- `npm run library:structure` 會依 `dimensions` 檢查每條 comment 是否符合所屬面向的詞彙；屬於多面向者，至少符合其中一個面向即可，不再要求所有 comment 都含結構詞。
- `npm run library:wording` 檢查總評、佳句、結構不得使用引號；`npm run junior:check` 另檢查字數、重複、變數與 Markdown 同步。
- 國中版每條 comment 的 `tags` 加入 `面向-結構`、`面向-立意`、`面向-語言`、`面向-情感`、`面向-格式` 方便搜尋；高中職版由 Markdown 轉檔，不逐一加面向標籤，面向歸屬以 coverage JSON 為準。
- 同一個 comment 可以支援多個面向與多個分類，但同一面向內的評語要分別處理不同症狀與調整策略，不可只換句型。
- 第 17–19 類是體裁補充（記敘、抒情、議論），由使用者提供評語表抽取概念改寫；不直接收錄特定題材、短標籤、修辭標籤或學習態度評語。
- 總評必須可獨立使用、不假設特定題材、人物、物件、地名或事件，也不使用引號。
- 錯字與語句的規則示例不列入 comment 類；本檔只用來校正總評。
- 目前 runtime 仍只載入 `senior.json`；國中版維持草稿，待老師校閱後再接。
