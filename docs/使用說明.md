# 作文批閱使用說明

> 版本 0.1.0（M7）｜ 適用 Windows 10 22H2 以上（x64）
>
> 作文批閱是 local-first 的桌機工具：資料庫就是你選的資料夾，程式不連網、不上傳、不埋 telemetry。批注、分數、名單、回饋單與統計都在本機完成。

---

## 1. 安裝版與 portable 的差異

安裝程式提供兩種形式：

| 形式 | 檔名 | 特性 |
|---|---|---|
| 安裝版 | `EssayGrader-0.1.0-Setup.exe` | 可選安裝路徑、建立桌面與開始功能表捷徑、可從「應用程式與功能」解除安裝 |
| 免安裝版 | `EssayGrader-0.1.0-Portable.exe` | 單一 exe，直接執行；適合放在隨身碟或沒有安裝權限的電腦 |

兩者功能相同，**資料庫都不會自動放在程式資料夾**。第一次使用都要自己選一個資料夾當資料庫。

- 安裝版與 portable 可以共存，但**不要同時開啟同一個資料庫**；程式有單一實例與 `.essay-grader.lock` 雙重保護。
- 設定與日誌會放在 Windows 使用者資料夾（`%APPDATA%\作文批閱`）。portable 不會把日誌寫在 exe 旁邊。
- 換電腦時，備份資料庫資料夾即可；程式本身重新安裝或複製 portable exe 都能延續使用。

### 系統需求

- Windows 10 22H2 或 Windows 11，x64。
- 建議 8 GB 記憶體；大量 2600px 掃描頁時記憶體約 300–500 MB。
- 不需要網路。只有第一次下載安裝檔或更新程式時需要。

## 2. 第一次開啟資料庫

1. 啟動「作文批閱」。
2. 按右上角「開啟資料庫」。
3. 選一個資料夾：
   - 新學期：建議建立新的空資料夾，例如 `D:\作文批閱\114-1`。
   - 既有資料：直接選原本的 `essay-grader-data` 或它的上層資料庫資料夾。
4. 選好後，左側會列出這個資料庫裡的班級。

資料庫資料夾的結構如下（資料夾名稱全 ASCII，中文只存在 JSON）：

```
114-1/
  C302-2025F/                 ← 班級
    class.json                ← 班名、教師、名單
    E20250107/                ← 作業
      assignment.json         ← 題目、量規、規則
      S07/                    ← 學生（座號）
        p1.jpg                ← 頁面圖片
        work.json             ← 批注、分數、總評
        S07_feedback.pdf      ← 匯出的回饋單
      _stats/                 ← 統計 CSV
      _inbox/                 ← 手機上傳暫存
```

### 資料庫鎖

開啟資料庫時會建立 `.essay-grader.lock`，記錄程式 pid 與電腦名稱。

- 同一台電腦若上次程式異常關閉，殘留的鎖會自動接手。
- 如果顯示「資料庫已被其他程式開啟」，請先關閉另一個視窗，或確認沒有另一個 portable 版本正在執行。
- 正常按「關閉資料庫」會釋放鎖；直接關閉程式也會嘗試釋放。

### 建議的存放位置

- 放在本機磁碟（例如 `D:\`）最穩定。
- 不要讓 OneDrive／Google Drive／Dropbox **即時同步**資料庫資料夾；同步衝突可能同時改寫 JSON。雲端只適合放**備份 zip**。
- 每個學期一個資料庫資料夾，避免同一資料夾累積多年資料。

## 3. 建立班級與作業

### 建立班級

1. 左側「班級」按「新增」。
2. 填班號、班名、年段（國中／高中／高職）、學年度、學期、教師。
3. 按「建立」。

班級資料夾會依「班號＋學年度＋學期」自動命名，例如 `C302-2025F`。同一個資料庫不能建立完全相同的班級代號。

### 建立作業

1. 先在左側選一個班級。
2. 在「作業」卡片按「新增」。
3. 填題目、題幹、截止日，選量規（均衡／內容導向／語言導向）。
4. 按「建立」。

作業資料夾依日期命名，例如 `E20261119`；同一天建立第二份會自動加 `-02`。

---

## 4. 以 Excel 匯入名單

1. 選好班級後，在名單卡片按「匯入 Excel」。
2. 選 `.xlsx` 檔。程式讀**第一個工作表**。
3. 前 10 列會自動尋找表頭：
   - 座號欄：標題含「座號」。
   - 姓名欄：標題含「姓名」或「名字」。
4. 找不到表頭時，會退回「A 欄座號、B 欄姓名，從第 1 列開始讀」。

規則：

- 座號會正規化成兩位數，例如 `7` → `07`。
- 新座號新增；同座號更新姓名；不會刪除 Excel 裡沒出現的舊學生。
- 空白姓名、無效座號會跳過並在結果提示。
- 匯入後記得按「儲存名單」。也可以直接在名單表格手動修改座號、姓名、在學狀態。

## 5. inbox 匯入

手機或掃描器把圖片放進作業的 `_inbox`，桌機會自動配對。最簡單的方式：

1. 選班級與作業。
2. 在匯入佇列按「開啟 inbox」。
3. 把圖片與 sidecar JSON 放進去，關閉資料夾後回到程式，watcher 會自動匯入。

檔名規則：圖片與 sidecar 使用同一個主檔名，例如：

```
S07__20261119-0900__001.jpg
S07__20261119-0900__001.json
```

sidecar 內容起碼要包含：

```json
{
  "schema_version": 1,
  "class_id": "C302-2025F",
  "assignment_id": "E20261119",
  "seat": "07",
  "seq": 1,
  "session_id": "20261119-0900",
  "captured_at": "2026-11-19T09:00:00+08:00"
}
```

配對與安全規則：

- 座號必須在班級名單中且在學，否則移到 `_unmatched`。
- 同 page 重複（相同圖片 hash）會跳過。
- 缺少 sidecar、sidecar 格式錯誤、指向其他班級或作業，都會移到 `_unmatched`，原檔不刪。
- 沒有手機時，可按「模擬 10 檔」產生測試資料，走同一條 watcher 流程。

匯入後，佇列會顯示每份作品的狀態：待批、批閱中、已批。

## 6. 批閱與快捷鍵

在匯入佇列按某份作品的「批閱」，進入三欄式介面：

- 左欄：同作業其他作品，可直接切換。
- 中欄：頁面畫布。
- 右欄：批注編輯、評分、總評。

### 畫布操作

- 滑鼠滾輪：縮放。
- 拖曳：平移。
- 點畫布空白處：新增批注定位點。
- PageUp／PageDown：上一頁／下一頁。

### 快捷鍵

| 按鍵 | 功能 |
|---|---|
| `1` | 切換為「錯字」批注 |
| `2` | 切換為「語句」批注 |
| `3` | 切換為「結構」批注 |
| `4` | 切換為「佳句」批注 |
| `5` | 切換為「評語」批注 |
| `PageUp` / `PageDown` | 翻頁 |
| `Ctrl+Z` | 復原批注操作 |
| `Ctrl+Y` 或 `Ctrl+Shift+Z` | 重做 |

在輸入框、下拉選單或總評欄位打字時，數字鍵與復原鍵會保留給文字輸入，不會觸發批注快捷鍵。

### 批注與評語庫

- 五類固定批注：錯字、語句、結構、佳句、評語；另有「其他」。
- 錯字可填「錯字 → 正確字」，會用於回饋單與 G2 常錯字統計。
- 語句可選子類（不通順、語序、用詞、冗贅、語意不清、銜接、口語化、文白夾雜）。
- 右側可從內建評語庫插入常用評語；插入後仍可修改文字。
- 修改會在約 600ms 後自動儲存；完成批閱後會自動載入下一份待批作品。

## 7. 評分與量規

### 三組預設量規

| 量規 | 內容 | 結構 | 語言 |
|---|---:|---:|---:|
| 均衡版（預設） | 40 | 30 | 30 |
| 內容導向 | 45 | 25 | 30 |
| 語言導向 | 35 | 30 | 35 |

- 分項合計必須是 100。
- 錯字與標點扣分預設各 0.5 分，上限 10 分。
- 等第門檻可在批閱前調整；門檻由高到低排序，最低分不可重複。

### 調整量規

1. 進入批閱後、評分前，按「調整量規」。
2. 可改 preset、自訂分項配分、新增／刪除等第並修改名稱與最低分。
3. 儲存時會驗證：分項合計 100、等第至少一筆、名稱不可空白或重複、最低分 0–100 且不可重複。

注意：

- 變更量規**不會自動改寫已儲存的分數與等第**。
- 目前這份作品的預覽會用新量規重算，完成批閱時才寫入。
- 若作業已有評分，調整前會先確認。

### 總評規則

- 總評至少 30 字（去空白與標點後計算）。
- 同一作業、同一批作品，完全相同（正規化後）的總評最多重複 2 次；第 3 次會阻擋。
- 完成批閱前會檢查未評分、總評不足等問題。

## 8. 回饋單列印與 PDF

作品標為「已批」後：

- 匯入佇列該列會出現「回饋單」。
- 批閱畫面右下角也有「回饋單」按鈕。

預覽視窗提供：

- **列印**：交給系統印表機。
- **匯出 PDF**：固定存到 `S{座號}/S{座號}_feedback.pdf`。
- **另存 PDF**：預設中文檔名，例如 `高中302_我的母親_S07_王小明_回饋單_2026-11-19.pdf`。

回饋單是一頁 A4，只印分數、等第、扣分、分項、總評、詞句改寫、常錯字與佳句，**不印原始作文圖**。內容過長時會自動縮小字級；仍放不下會阻擋匯出並提示縮短總評或減少批注。

---

## 9. 統計與 CSV

在匯入佇列按「統計」，可看：

- 班級分數摘要：平均、中位數、最高、最低。
- 等第分布。
- 分項平均。
- **G1 弱項排行**：依批注類型／子類統計佔比與涉及人數。
- **G2 常錯字**：跨學生合併同一組「錯 → 正」，列出次數與座號。
- **G3 每人弱項**：每位學生前三弱項。

統計只計 `done`（已批）作品。未完成、未匯入的學生仍會列在個人表，但標示「不計入」，不影響班級數字。

按「匯出 CSV」會在該作業資料夾的 `_stats/` 產生四個檔：

- `scores.csv`
- `weakness-ranking.csv`
- `common-typos.csv`
- `student-weakness.csv`

皆為 UTF-8 BOM＋CRLF，可直接用 Excel 開啟；重複匯出會覆寫同名檔。

## 10. 備份與還原

### 備份

1. 開啟資料庫後，按右上角「備份資料庫」。
2. 選儲存位置；預設檔名為 `essay-grader-backup-YYYYMMDD-HHmm.zip`。
3. 完成後會提示備份檔數與大小。

備份內容是**整個資料庫根目錄的相對路徑**，包含：

- 班級 `class.json`
- 作業 `assignment.json`
- 學生 `work.json`
- 頁面圖片、縮圖
- `_stats/` CSV
- 原子寫入留下的 `.bak`

備份會排除：

- `.essay-grader.lock`
- 所有 `*.tmp`（含 `*.restore.tmp`）

zip 內不會出現磁碟代號或絕對路徑。備份檔名不含學生姓名。

### 還原

1. 按「還原備份」。
2. 選 zip。
3. 選一個**新的空資料夾**。
4. 程式解壓後會直接以新資料夾開啟資料庫。

安全規則：

- 目的地不是空資料夾 → 直接拒絕，不會覆寫。
- 不能還原到目前開啟的資料庫、它的子資料夾或上層資料夾。
- 會先檢查 zip 內所有路徑；含絕對路徑、磁碟代號、`..`、符號連結或重複路徑一律拒絕（zip slip 防護）。
- 若 zip 含檔案但沒有 `class.json`，會視為「不是作文批閱資料庫」並停止。
- 解壓失敗時會清掉這次寫入的內容，不會留下半套資料。

還原成功後，舊資料庫仍原封不動；確認新資料庫無誤再決定是否刪除舊的。

### 建議節奏

- 每次大批匯入或批完一個作業後備份一次。
- 學期末把備份 zip 另存到雲端或外接硬碟。
- 備份 zip 與資料庫資料夾不要放在同一個即時同步資料夾。

## 11. M: 固定磁碟腳本

專案路徑約定為 `M:\dev\projects\essay-grader`。若把專案磁碟接到新主機後拿到其他代號：

1. 關閉所有使用該磁碟的程式與終端機。
2. 以**系統管理員**開啟 PowerShell。
3. 在專案資料夾執行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\fix-m-drive.ps1
```

腳本會把專案所在磁碟區改成 `M:`：

- 已在 `M:` 時不變更。
- `M:` 已被其他磁碟占用時會停止並提示先釋放。
- 變更磁碟代號需要系統管理員權限；完成後重新開啟終端機與編輯器。

這個腳本只影響開發環境；一般使用者不需要執行。

## 12. 日誌位置與回報問題

按右上角「開啟日誌」會開啟日誌資料夾。預設位置：

```
%APPDATA%\作文批閱\logs\app.log
```

- 每筆含 ISO 時間、level（INFO／WARN／ERROR）與訊息。
- `app.log` 超過約 2 MB 會輪替為 `app.1.log`，避免無限成長。
- 主程序未捕捉的錯誤、未處理的 Promise rejection、畫面程序結束、載入失敗都會寫入。
- React 畫面發生錯誤時會顯示友善錯誤畫面，可重新載入或開啟日誌，不會只剩空白視窗。

隱私原則：日誌只記錄**事件與錯誤訊息**，不記錄學生姓名、總評全文、批注全文或圖片內容。回報問題時可提供 `app.log` 與 `app.1.log`；若仍擔心，可先自行開啟確認。

## 13. 隱私與資料安全

- 不連網、不上傳、不埋 telemetry。
- 資料庫是普通資料夾，可自行用檔案總管備份、複製、壓縮。
- 匯入圖片時會轉正、移除 GPS／中繼資料並產生縮圖。
- 回饋單與統計只寫在本機資料庫資料夾。
- 日誌不含學生姓名、總評、批注全文或圖片內容。
- 程式沒有學生帳號、沒有雲端同步、沒有 AI 評分。

## 14. 常見問題

### Q：開啟資料庫時說「資料庫已被其他程式開啟」

先關閉另一個作文批閱視窗或 portable 版本。若確定沒有其他程式，可能是上次異常關閉留下鎖檔；同機且程序已結束時會自動接手。仍無法開啟時，確認 `.essay-grader.lock` 的電腦名稱是不是別台電腦（例如資料庫放在共用磁碟）。

### Q：還原時說「目的地不是空資料夾」

程式不覆寫既有資料。請新建一個空資料夾，或把原本資料夾裡的東西先移到別處。也不要選目前資料庫或其子資料夾。

### Q：還原時說「這個 zip 看起來不是作文批閱資料庫備份」

zip 內沒有任何 `class.json`。請確認選到正確的備份檔，而不是一般壓縮檔或圖片包。

### Q：Excel 名單匯入後人數不對

程式只新增與更新，不會刪除舊名單。請檢查 Excel 的座號欄是否被辨識為文字或數字、姓名是否空白；結果提示會列出跳過的列。也可以在名單表格手動修正後按「儲存名單」。

### Q：inbox 的檔案沒有進來

檢查：

1. 圖片與 sidecar 是否同主檔名。
2. sidecar 的 `class_id`、`assignment_id`、`seat` 是否正確。
3. 座號是否在名單中且在學。
4. 檔案是否被移到 `_unmatched`（原因會寫在旁邊或匯入狀態）。

### Q：回饋單無法匯出 PDF

通常是內容超過一頁 A4。請縮短總評、減少批注，或降低批注字數；程式會自動降到最小字級，仍放不下才阻擋。

### Q：統計數字和想像不同

統計只計 `done` 作品；`pending`、`grading`、未匯入都不計入班級數字。G1 以「弱項批注總數」為分母，佳句不列入弱項。CSV 的個人表仍會列出未計入的學生。

### Q：換電腦後資料怎麼搬？

複製整個資料庫資料夾，或在新電腦用「還原備份」。還原一定要選新的空資料夾。程式設定與日誌不需要搬。

### Q：可以同時開兩個視窗批閱嗎？

不行。程式限制單一實例，且資料庫有鎖，避免兩個 writer 同時寫入。

### Q：portable 版放在隨身碟，資料會存在隨身碟嗎？

不會。資料庫位置由你第一次開啟時選擇；程式設定與日誌在使用者資料夾。若要把資料帶著走，請把資料庫資料夾也放在隨身碟，並在每台電腦重新「開啟資料庫」指向它。

## 15. 目前版本限制（0.1.0）

- 只支援 Windows x64；尚無 macOS／Linux 安裝檔。
